# Solo English

유튜브(하루영단어·여행영어 등)와 EBSe 회차를 목록에 남기고, 완료하면 아래로 보내며 따라 말하는 로컬/웹 앱입니다.

## 사이트

https://joko8145.github.io/solo-english/

## 사용

1. 유튜브 또는 EBSe에서 영상을 본다.
2. 주소를 **공부한 회차 추가**에 붙여 넣는다. (`list=`가 있으면 하루영단어·여행영어 등이 자동 분류)
3. 목록에서 열어 따라 말하고, **공부 완료**하면 아래(완료)로 간다.

## 폰 ↔ PC 동기화

브라우저 저장은 기기마다 다릅니다. 같은 GitHub 토큰으로 맞춥니다.

1. GitHub → Settings → Developer settings → Personal access tokens (classic)
2. `gist` 권한만 켠 토큰 생성
3. Solo에서 토큰 입력 → **올리기** (한쪽) → 다른 기기에서 같은 토큰으로 **받기**

토큰 없이 옮기려면 **목록 복사 / 목록 붙여넣기**를 쓰세요.

## 로컬

`index.html` 또는 `열기.bat`
